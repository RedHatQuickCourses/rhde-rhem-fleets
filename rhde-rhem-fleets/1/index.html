Managing Edge Device Fleets and Applications with Red Hat Edge Manager

Goal

This course teaches how to configure, manage, and monitor edge devices at scale by grouping them into device fleets with Red Hat Edge Manager and how to deploy containerized applications in devices of a fleet.

Objectives

On completing this course, you should be able to:

  • Understand the challenges of managing edge devices at scale

  • Create and Manage Device Fleets

  • Monitor and Troubleshoot Devices and Fleets

  • Configure and Manage Quadlet Applications

Audience

  • Operations-focused customer roles, who manage edge devices, but are not usually in-person at edge sites:

  • System Administrations (IT and OT)

  • Site Reliability Engineers (SREs)

  • Platform Engineers and DevOps Engineers

  • Red Hat and Partner roles that perform demonstrations, PoC and PoV of Red Hat Edge Manager as part of a sales motion, such as Solutions Architects.

  • Red Hat and Partner roles that implement and support Red Hat Edge Manager on customers, such as Services Consultants, Technical Account Managers, and Customer Support Engineers.

Prerequisites

This course assumes that you have the following experience:

  • Familiarity with RHEL system administration, to the level of RHCA (Red Hat Certified System Administrator) or equivalent knowledge.

  • Familiarity with Linux container tools, such as Podman, and technologies compatible with Open Container Initiative (OCI) specifications, such as container registries.

  • Familiarity with image mode for RHEL, especially building bootc container images and provisioning and updating image mode systems.

It’s recommended that learners already prossess skills from the image mode with Red Hat Device Edge quick course series.

  • Having completed or having equivalent skills to Deploying Red Hat Edge Manager and Managing Edge Devices.

Notice that no prior knowledge of Kubernetes and OpenShift is assumed nor required.
